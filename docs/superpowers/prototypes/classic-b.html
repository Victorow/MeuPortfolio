03Open source · MCP

Duo

Ponte MCP entre duas instâncias do Claude Code: um Tech Lead delega trabalho a um Executor em outra máquina.

TypeScriptMCPNode.jsTailscale
+

Desafio

Um único agente não consegue ter, ao mesmo tempo, a visão do líder técnico e as mãos no projeto em outra máquina.

Solução

Servidores MCP nos dois lados, rede via Tailscale, cache semântico local, delegação de tasks e barreira de publicação por branch protegida.

Impacto

Fluxo agente-a-agente funcional, com contenção real de risco no Git.

04Open source · Node.js e Rust

claude-telegram-bridge

Bridge self-hosted que avisa no Telegram quando uma sessão do Claude Code termina e permite continuar pelo chat.

Node.jsRustTelegram Bot API
+

Desafio

Sessões longas de agente exigiam ficar na frente do computador para saber quando acabavam ou precisavam de uma decisão.

Solução

Binário por sistema operacional, long-polling sem servidor público, múltiplos projetos e usuários em um só bot, hooks instalados automaticamente.

Impacto

Publicado com releases por OS; configuração em dois passos.

Sou FullStack Developer em São José dos Campos. Hoje atuo como Desenvolvedor Júnior na CDT Software, com front-end em React/Vite, back-end hospedado na AWS e bancos PostgreSQL. Antes, fui estagiário no SESI, em sistemas internos, automação e infraestrutura.

Nos últimos tempos, construo ferramentas que tornam fluxos com agentes de IA (MCP, Claude Code) utilizáveis no dia a dia: uma ponte entre duas instâncias do Claude Code, uma bridge para o Telegram e extensões para o VS Code.

Escrevo código com intenção, priorizo legibilidade e trato performance e segurança como requisito, não como ajuste final. Português nativo, inglês intermediário.
