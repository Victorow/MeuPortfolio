# Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Phase 2 of the portfolio: classic no-3D route with two switchable designs, full SEO/GEO, security baseline, OG/sitemap/robots/llms, themed 404, "60 seconds" mode, Mission Control, photo mode, Sun lens flare + Moon eclipse, warp sound sync.

**Spec:** `docs/superpowers/specs/2026-10-13-phase-2-design.html` (full, with UI mockups) and `.md` (summary). Prototypes: `docs/superpowers/prototypes/classic-a.html` (paper editorial) and `classic-b.html` (dark dossier). Both designs must ship, with a switch and a fluid transition.

**Architecture:** Next 14 static export (`output: 'export'`, trailingSlash), next-intl (pt-BR default, en), R3F scene in `components/scene`, journey UI in `components/journey`, content in `content/*.ts` + `messages/*.json`. Classic route is pure server components + CSS (no JourneyShell), reading the same content.

**Tech Stack:** Next 14.2, React 18, TypeScript, Tailwind 3, next-intl 3, R3F 8, drei 9, three 0.169, GSAP 3, zustand, Vitest 3, Playwright.

## Global Constraints

- Static export only. No server code, no API routes, no runtime secrets.
- Every user-visible string in `messages/pt-BR.json` and `messages/en.json`.
- Colours: black, white, one blue. No cards with shadows, gradients, rounded "glass" boxes, emojis.
- Do NOT show any "available / open to work" status anywhere.
- Marketplace links for VS Code extensions stay hidden (TODO-VICTOR).
- No Cloudflare. GitHub Pages only. Security headers via `<meta http-equiv>` where possible.
- Tests: `npm run test` (Vitest), `npx tsc --noEmit`, `npx next lint`, `npm run build:e2e` (exports to `.next-e2e/`), `npm run e2e` (Playwright, port 3100, serves `.next-e2e`). Never run `npm run build` (it clobbers the user's `.next`).
- No commits. The orchestrator commits after validation.

### Task 4: Security baseline

**Files:** Modify `app/[locale]/layout.tsx` + classic layout (CSP meta: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self'; connect-src 'self'; worker-src 'self' blob:; object-src 'none'; base-uri 'self'; form-action 'none'; upgrade-insecure-requests`, plus `referrer`, `X-Content-Type-Options` is header-only so skip), audit all `target="_blank"` for `rel="noopener noreferrer"`, `.github/workflows/deploy.yml` (actions pinned by full SHA, minimal permissions, `npm audit --audit-level=high` step, `npm ci`), `scripts/strip-pdf.mjs` (pypdf-free: use `pdf-lib` to clear metadata; run in `seo:build`), `.github/dependabot.yml`.
- Verify CSP does not break GSAP/R3F (inline styles allowed; no inline scripts except JSON-LD which is `type=application/ld+json`, not executed → allowed). Next.js static export injects inline scripts for hydration → `script-src 'self'` will BLOCK them. Resolve: use `'unsafe-inline'` for script-src only if unavoidable, and document; prefer nonce-less approach: Next inline scripts are required, so CSP must be `script-src 'self' 'unsafe-inline'`. State this in a comment.
